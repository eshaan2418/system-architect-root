

# Eshaan Kapooswalla — Personal Engineering Portfolio

A pitch-black, minimal, and technical personal website that communicates serious engineering credibility without any fluff.

---

## Design System
- **Background**: Pure black (#000000) throughout
- **Typography**: Bold sans-serif headers, clean sans-serif body, monospace for dates/tech stacks/locations
- **Colors**: White primary text, soft gray secondary, subtle cool-blue on hover only
- **Animations**: Smooth scroll, fade-in on section reveal, underline hover effects, subtle card lift (2-3px)
- **No gradients, no emojis, no icons (except social links), no decoration**
